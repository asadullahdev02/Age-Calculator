# 📅 Age Calculator

A modern, responsive Age Calculator web application built using **React, Vite, and Tailwind CSS**. Calculate exact age in years, months, and days, along with milestone statistics and zodiac signs.

---

## ✨ Features

- **Exact Age Precision**: Computes exact chronological age down to the day with leap year compensation.
- **Life Milestones**: Displays total days lived and elapsed weeks.
- **Next Birthday Countdown**: Real-time counter showing days remaining until the user's next birthday.
- **Astrological Zodiac Sign**: Automatically calculates Western astrological zodiac sign with symbol.
- **Validation**: Enforces date boundaries (no future dates) and displays interactive error alerts.
- **Mobile Responsive**: Clean card interface designed for mobile phones and desktops with gradient styling.

---

## 🛠️ Tech Stack

- **React 18**: Component architecture and state hooks (`useState`)
- **Vite**: Rapid frontend development tooling and bundler
- **Tailwind CSS**: Utility-first responsive design

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/asadullahdev02/Age-Calculator.git
   cd Age-Calculator
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
